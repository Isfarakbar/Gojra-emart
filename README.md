# Gojra E-Mart

A city-level e-commerce app MVP built with Flutter and Node.js.

## Tech Stack
- **Frontend:** Flutter (Mobile App + Admin Web)
- **Backend:** Node.js + Express
- **Database:** MongoDB Atlas
- **Images:** Cloudinary
- **Auth:** JWT
- **Integration:** WhatsApp Business Cloud API

## Structure
- `backend/`: Node.js server code
- `frontend/`: Flutter application code

## Getting Started

### Backend
1. `cd backend`
2. `npm install`
3. Setup `.env` file
4. `npm start`

### Frontend
1. `cd frontend`
2. `flutter pub get`
3. `flutter run`
